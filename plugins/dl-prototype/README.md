# dl-prototype

The prototype tier of design-led SDD: light, design-led specs for game teams working with AI agents while the game is still finding its fun.

Eight skills (constitution, adopt, spec, brief, clarify, analyze, tasks, playtest) set up a new or existing project, write feature specs and short briefs, gate specs through clarify and analyse checks, hand them to tickets as job stories with Gherkin acceptance criteria, and fold playtest results back into the spec. Every question is asked one at a time, as multiple choice.

Start a new game with `/dl-prototype:constitution`, or bring an existing one in with `/dl-prototype:adopt`. The repository README has the full guide; `principles/` explains the method.
