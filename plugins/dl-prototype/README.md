# dl-prototype

The prototype tier of design-led SDD: light, design-led specs for game teams working with AI agents while the game is still finding its fun.

Seven skills (constitution, spec, brief, clarify, analyze, tasks, playtest) set up a project, write feature specs and short briefs, gate specs through clarify and analyse checks, hand them to tickets as job stories with Gherkin acceptance criteria, and fold playtest results back into the spec. Every question is asked one at a time, as multiple choice.

Start with `/dl-prototype:constitution` in a game project. The repository README has the full guide; `principles/` explains the method.
